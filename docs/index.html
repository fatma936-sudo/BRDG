Boundary-Responsive Differentiable Gating for Superpixel-Based Segmentation

BRDG · Y = (1 − g) · Yc + g · Yr

Fatmaelzahraa Ali Ahmed1, Zhihe Lu2, Gianni Di Caro3, Diram Tabaa3, Mohamed Hamdy4, Muraam Abdel-Ghani1, Abdulaziz Al-Ali4, Muhammad Arsalan5, Shidin Balakrishnan1†

1Hamad Medical Corporation · 2Hamad Bin Khalifa University · 3Carnegie Mellon University Qatar · 4Qatar University · 5KINDI Center, Qatar University · †corresponding author

Paper (coming soon) Code Weights (v0.1) Video Poster

  • +4.5 to +7.0mIoU over pixel-wise baselines
  • over +10BF1 (boundary F1) points
  • 150.3 FPSon an RTX-A6000 Pro
  • 23.9 Mparameters · ×10 faster, ×3.5 smaller than SOTA

BRDG is one differentiable network with three cooperating agents. A ResNet-34/U-Net backbone emits soft superpixel assignments A and coarse logits Yc; a small boundary detector scores each region and re-projects the scores through A into a dense gate g; a dual-path refinement head is blended as Y = (1 − g)·Yc + g·Yr, so refinement is spent only along predicted boundaries. The result is +4.5 to +7.0 mIoU over pixel-wise baselines and over +10 BF1 points, at 23.9 M parameters and 150.3 FPS on an RTX-A6000 Pro — ×10 faster and ×3.5 smaller than SOTA.

three agents · one differentiable network

Method

Y = (1 − g) · Yc + g · Yr

g is the dense boundary gate; refinement is applied only where g is high.

Agent 1

Region & Feature Creator

ResNet-34/U-Net backbone produces dense feature map F. Two 1×1 heads emit superpixel assignment logits and coarse logits Yc; temperature softmax yields soft assignments A; soft-pooling gives K region descriptors rk.

Agent 2

Boundary Detector

A small MLP maps each region descriptor rk to a boundary probability pk in [0,1]. Re-projection through A yields a dense pixel-wise gate g, supervised by a ground-truth boundary map via BCE.

Agent 3

Refinement Agent

A dual-path classifier: a coarse 1×1 path predicts Yc; a refined MLP path operates on region descriptors to give Yr. The gate blends them: Y = (1 − g)·Yc + g·Yr, refining only along predicted boundaries.

Why the gate matters

The learned gate (0.72) outperforms either coarse-only or refine-only. Removing refinement costs 11 mIoU points and improves neither speed nor memory: runtime stays 6.63 ms, peak memory rises 1.05 → 1.17 GB. Gate=0 reproduces No-refine (0.61).

Superpixel count

On BSDS500 by Boundary Recall, optimum is K = 500 (BR 0.67); beyond that assignments become overly fragmented and performance degrades, worst at K = 1000.
